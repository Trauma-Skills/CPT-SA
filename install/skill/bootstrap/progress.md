## How to read this file

Claude keeps this current so you never have to. All times are real-clock timestamps. The course opens with the **starting point** — an untimed conversation about what brings you here, closing with a short baseline check-in; it can be skipped, and session 1 follows it immediately either way. After that, the next session opens at the *later* of (current homework complete) and (last session end + 72 hours); a session's homework may also have its own unlock delay after that session ends — a burnout buffer, see the homework schedule in the `cpt-sa` skill. Session 1 is exempt from the floor. The **▶ Next step** line always states the one thing to do next and when. Claude refreshes this block at every session close and whenever homework status changes.
