# Sessions

One folder per session: `NN-name/`. Each will contain:

- `guide.md` — the facilitation script for that session (adapted from the manual's session plan): the flow, the Socratic prompts, when to surface each handout, the homework to assign, and the completion criterion.
- `handouts/` — the client handouts for that session, as individual markdown files, surfaced alongside the chat at the right moment. **Filename convention:** name each file after its H1 title, spaces and punctuation included, minus any Windows-illegal characters (`? * : " < > | \ /`) — e.g. "Rules — what are they?" → `Rules — what are they.md`. The file chip displays the filename, so it's user-facing text. Markdown links to these paths need angle brackets: `[title](<path with spaces.md>)`. (Working files in `my-work/` stay kebab-case.)
